# マップ集客ラボ レベルチェッカー

GoogleマップMEOの無料診断を発行し、営業メンバーの追客・成約までを管理する「診断ドリブンの営業システム」。
マップ集客ラボV3の診断エンジン・デザインを流用。

## 機能

- **診断発行**（営業）：訪問前にお客様のGBP状況を6カテゴリで入力 → 公開URL/QRを発行
- **診断結果**（お客様）：4色スコア・ランク・優先対策。**PDF保存/印刷**・**LINEで無料トライアル申込**CTA
- **営業ダッシュボード**：今月の発行数（目標進捗）・トライアル実施率・診断一覧（ステータス変更／結果／QR／PDF／削除）
- **ステータス**：訪問前 → 検討 / トライアル導入 / 本契約 / 失注（後から手動変更）
- **管理ボード**：全体/営業別の進捗を円・棒グラフで可視化。本契約率(CVR)。営業アカウント発行、月間目標変更、LINE URL設定
- **認証**：アカウントリンク方式（`/s/<token>` を開けばその営業としてログイン。管理者は `/a/<ADMIN_TOKEN>`）

## セットアップ

```bash
npm install
cp .env.example .env   # 値を設定
npm run dev            # http://localhost:3000
```

## 環境変数

| 変数 | 用途 | 必須 |
|---|---|---|
| `ADMIN_TOKEN` | 管理者ログインリンク `/a/<ADMIN_TOKEN>` のトークン | ✅ |
| `REDIS_URL` | Upstash/Vercel Redis（診断・営業データの保存）。未設定時はメモリ動作（再起動で消える） | 本番◎ |
| `LINE_ADD_URL` | 診断結果のLINE無料トライアルCTAのURL（管理画面でも設定可） | 任意 |
| `SERVER_SECRET` | 予備 | 任意 |

## 使い方（運用フロー）

1. 管理者が `/a/<ADMIN_TOKEN>` でログイン → 管理ボードで営業アカウントを発行 → **アカウントリンク**を各営業に共有
2. 営業がアカウントリンクからログイン → 訪問前に「新規診断を発行」→ お客様にURL/QRを共有 or PDFを印刷して手渡し
3. お客様が結果を見てLINEから無料トライアル申込
4. 営業が案件のステータスを更新（検討／トライアル導入／本契約／失注）
5. 管理者が全体・営業別の進捗と本契約率をボードで確認

## 技術

Next.js 14 (App Router) / TypeScript / ioredis / qrcode。チャートは依存なしの自作SVG。
診断ロジックは `lib/domain/`（vitestでテスト）、データは `lib/store/`（Redis＋メモリfallback）。
